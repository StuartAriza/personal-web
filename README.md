# Raul Boonstra-Ariza — Portfolio

Personal portfolio built with React + Vite, styled with Tailwind, and animated with Framer Motion.  
Includes project highlights, resume, contact form (Netlify Forms), and a photography gallery.

## Live
- Site: https://raulboonstra-ariza.netlify.app/
- Domain: In the works! 

## Tech Stack
- React + Vite
- Tailwind CSS
- Framer Motion
- React Router
- Netlify (hosting + forms)

## Pages
- **Home** — intro + featured projects + tech stack
- **Projects** — project cards and details/links
- **Resume** — downloadable PDF + web version
- **Photography** — personal gallery (local images)
- **Contact** — Netlify Forms contact form
